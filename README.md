# 🧠 Student Wellness App

A personal project focused on improving student productivity and mental well-being through simple, interactive tools.


## 🚀 Why I Built This

I originally worked on a similar idea during Smart India Hackathon, but I didn’t truly build it myself.  
That always bothered me.

So I came back and rebuilt this project from scratch — this time understanding every part of it.

## ✨ Features

- 💬 Mood Chat Interface  
- 📚 Task Management System  
- 🔁 Habit Tracker (with daily completion tracking)  
- 📝 Personal Journal  
- 🧠 Mental Support Guides (panic, anxiety, etc.)  
- 📊 Dashboard with progress & insights  
- ⭐ Gamified Points System (tasks + habits + engagement)

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **State Management:** React Hooks + LocalStorage
- **Auth & Backend Services:** Firebase
- **Deployment:** GitHub Pages

## 🔐 Security

- Firebase config moved to `.env`
- API keys are not exposed in the repository

## 🧠 What I Learned

- Building a full React app from scratch  
- Managing state and persistence (localStorage)  
- Debugging UI/logic issues instead of restarting  
- Using Firebase properly  
- Securing environment variables

This project is not meant to be a full production app, but a functional and thoughtful prototype built for learning and improvement.
